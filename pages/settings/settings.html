    Security information

    • Chrome Profile Guard does not send your password or PIN to any server.
    • Your authentication data is stored locally and only as a salted, derived key — never as plaintext.
    • Chrome extensions cannot control Chrome's native profile picker or sign-in. This is a browsing-workspace lock.
    • A user who can disable or uninstall the extension can bypass it. For device-level security, use your operating system lock.
